중앙대 e-Class · iPad / iPhone

과제 한눈에 북마클릿

아이패드 사파리에는 크롬 확장을 설치할 수 없습니다. 대신 북마크 하나를 만들어 두면, e-Class에서 그걸 누를 때마다 모든 과목의 과제 마감일이 D-day 순으로 뜹니다. 붙여넣을 코드는 세 줄 남짓입니다.

버튼이 안 먹히면 위 칸을 길게 눌러 전체 선택 → 복사

인터넷 없이 쓰는 전체 버전 (길어서 복사가 번거롭습니다)

위 짧은 버전은 실행할 때 코드를 인터넷에서 내려받습니다. 그게 막히는 환경이라면 아래 전체 버전을 쓰세요. 동작은 완전히 같지만 길이가 19KB라 손으로 복사하기 어렵습니다.

설치

  1. 북마크를 하나 만듭니다

    사파리로 eclass3.cau.ac.kr 에 접속해 로그인한 뒤, 공유 → 북마크 추가 → 이름을 과제 한눈에로 바꾸고 위치를 즐겨찾기로 둔 채 저장합니다.

  2. 주소를 통째로 바꿉니다

    사파리 북마크 목록(책 아이콘)에서 편집 → 방금 만든 북마크를 탭 → 아래쪽 주소 칸의 내용을 전부 지우고, 위에서 복사한 것을 붙여넣습니다.

  3. e-Class에서 누릅니다

    로그인된 e-Class 화면에서 주소창을 탭하면 즐겨찾기에 과제 한눈에가 보입니다. 그걸 누르면 과제 목록이 화면 위로 올라옵니다. 한 번 더 누르면 닫힙니다.

  4. 캘린더에 넣어둡니다

    목록 아래 캘린더에 넣기 (.ics)를 누르면 마감일이 애플 캘린더로 들어갑니다. 하루 전 알림이 같이 걸려 있어서, 매번 북마크를 누르지 않아도 됩니다.

앱처럼 쓰기 (iOS 단축어)

단축어로 만들면 e-Class에서 공유 한 번으로 열립니다. 홈 화면에 아이콘으로도 놓을 수 있어서, 북마크 목록을 뒤지지 않아도 됩니다. 붙여넣을 내용만 다르고 하는 일은 똑같습니다.

  1. 단축어 앱에서 새로 만들기

    단축어 앱 → 오른쪽 위 + → 동작 추가

  2. 동작 하나만 넣습니다

    웹 페이지에서 JavaScript 실행을 검색해 추가하고, 그 안의 코드를 전부 지운 뒤 위에서 복사한 것을 붙여넣습니다.

  3. 공유 시트에 올립니다

    아래 정보 버튼 ⓘ → 공유 시트에 보기를 켜고, 이름을 과제 한눈에로 저장합니다.

  4. e-Class에서 공유 → 과제 한눈에

    홈 화면 아이콘으로 두고 싶다면, 단축어를 길게 눌러 홈 화면에 추가를 고르세요. 단, 실행은 e-Class 화면이 열려 있을 때 해야 합니다.

안 될 때

로그인 안내가 뜸 e-Class 세션이 풀린 겁니다. 로그인을 다시 하고 북마크를 누르세요.
아무 일도 안 일어남 주소 칸에 javascript: 로 시작하는 전체 문자열이 들어갔는지 확인하세요. 앞부분이 잘리면 사파리가 그냥 검색으로 처리합니다.
e-Class 밖에서 누름 다른 사이트에서는 동작하지 않습니다. 보안상 e-Class 페이지 안에서만 과제를 읽을 수 있습니다.
크롬에서 쓰고 싶음 아이패드 크롬은 북마클릿 실행이 까다롭습니다. 사파리를 쓰세요. 윈도우·맥 크롬에서는 북마클릿 대신 확장 프로그램 쪽이 낫습니다.
학번과 비밀번호는 어디에도 저장되지 않습니다. 이미 로그인된 e-Class 페이지 안에서 실행되기 때문에, 브라우저가 들고 있는 세션을 그대로 빌려 씁니다. 읽어온 과제 목록은 그 화면을 닫는 순간 사라지고, 외부로 전송되는 것은 없습니다.
