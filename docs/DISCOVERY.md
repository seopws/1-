# e-Class 엔드포인트 찾기

평소에는 볼 일이 없는 문서입니다. 기본 설정(중앙대 e-Class + 자동 감지)으로 그냥 돌아갑니다.

**언제 필요한가:** e-Class가 업그레이드되면서 API 경로가 바뀌었거나, 학교가 `/api/v1`을 막았거나,
과제가 일부만 나올 때. 그럴 때 **5분이면** 코드를 안 고치고 다시 맞출 수 있습니다.

---

## 방법 A. 확장 프로그램의 "탐색" 기능 (권장)

개발자도구를 몰라도 됩니다.

1. 확장 프로그램 **설정** 화면을 엽니다.
2. `1. LMS 연결`의 주소가 `https://eclass3.cau.ac.kr` 인지 확인합니다. (기본값)
3. `2. 엔드포인트 탐색`에서 **탐색 켜기**를 누릅니다.
4. e-Class 탭으로 가서 **과제 목록 / 할 일 / 강의실 메인**을 한 번씩 열어봅니다.
   (이미 열려 있다면 새로고침 `F5`)
5. 설정 화면으로 돌아와 **목록 새로고침**을 누릅니다.
   → 마감일처럼 생긴 필드(`due_at`, `end_date`, `deadline` …)가 들어 있는 응답만 걸러서 보여줍니다.
6. 제일 그럴듯한 항목의 **"이 엔드포인트로 설정 채우기"** 를 누릅니다.
   URL과 필드 매핑이 자동으로 채워집니다.
7. **연결 테스트** → 과제가 나오면 **저장**.

> 탐색은 페이지가 주고받는 응답을 *읽기만* 합니다. 아무것도 바꾸거나 전송하지 않고,
> 기록은 전부 내 브라우저 안(`chrome.storage.local`)에만 남습니다. 다 쓰면 **탐색 끄기**를 누르세요.

## 방법 B. 개발자도구로 직접 찾기

1. e-Class에 로그인한 상태에서 `F12` → **Network** 탭.
2. 필터를 **Fetch/XHR** 로 두고, 과제 목록 페이지를 새로고침.
3. 응답(Response)에 `due_at` / `end_date` / `deadline` 같은 필드가 보이는 요청을 찾습니다.
4. 그 요청을 우클릭 → **Copy → Copy link address**.

찾을 때 눈여겨볼 후보들:

| 성격 | 경로 예시 |
|---|---|
| Canvas 표준 할 일 | `/api/v1/planner/items?start_date=…` |
| Canvas 표준 미제출 | `/api/v1/users/self/todo` |
| Canvas 과목별 과제 | `/api/v1/courses/123/assignments` |
| 수강 과목 목록 | `/api/v1/courses?enrollment_state=active` |
| LearningX 확장 | `/learningx/api/v1/…` (e-Class에 `/learningx/` 경로가 있는 건 확인됨) |

---

## 찾은 값을 설정에 넣기

`3. 직접 지정 어댑터` 칸을 이렇게 채웁니다.

```
과제 목록 URL   /api/v1/courses/{courseId}/assignments?per_page=100
과제 배열 경로   (응답 최상위가 배열이면 비워둠. {"data":{"items":[…]}} 면 data.items)
제목 필드       name
마감일 필드     due_at
ID 필드         id
링크 필드       html_url
```

- `{courseId}` 를 쓰면 **과목 목록 URL**도 함께 필요합니다.
  (기본값 `/api/v1/courses?enrollment_state=active&per_page=100`, ID `id`, 이름 `name`)
- 필드 경로는 점 표기법을 씁니다: `assignment.due_at`, `data.items[0].name` 처럼 중첩도 가능.

## 그래도 API를 못 찾겠다면

`4. HTML 스크래핑`을 씁니다. 과제 목록 **페이지**의 HTML을 직접 긁습니다.

1. 과제 목록 페이지에서 `F12` → **Elements**.
2. 과제 한 줄(행)을 우클릭 → **Copy → Copy selector**.
3. 복사된 선택자에서 `:nth-child(3)` 같은 순번 부분을 지워 "모든 행"에 걸리게 만듭니다.
   예: `table.list tbody tr:nth-child(3)` → `table.list tbody tr`
4. 같은 방법으로 제목/마감일 칸의 선택자를 각각 구합니다.

```
목록 페이지 URL   /todo
행 선택자         table.list tbody tr
제목 선택자       td.subject a
마감일 선택자     td.deadline
과목명 선택자     td.course
```

마감일 칸에 "2026-03-14 23:59 까지" 처럼 글자가 섞여 있어도, 날짜 부분만 알아서 뽑아냅니다.

## 자주 막히는 지점

| 증상 | 원인과 해결 |
|---|---|
| `LMS 로그인 세션이 만료됐습니다` | e-Class 탭에서 다시 로그인하세요. 확장은 브라우저 세션을 빌려 쓰기 때문에, 로그인이 풀리면 못 가져옵니다. |
| `LMS 접근 권한이 없습니다` | LMS 주소를 기본값(`https://eclass3.cau.ac.kr`)에서 바꿨다면, 설정에서 **권한 허용**을 눌러야 합니다. |
| 테스트는 되는데 과제가 0개 | `과제 배열 경로`가 틀렸을 가능성이 큽니다. "샘플 보기"로 실제 JSON 모양을 확인하세요. |
| 과목명이 전부 `(과목 미상)` | `과목명 필드`가 응답에 없는 경우. `{courseId}` 방식으로 바꾸면 과목 목록에서 이름을 가져옵니다. |
| 마감일이 전부 "기한 없음" | `마감일 필드` 경로가 틀렸거나, 값이 `null`인 항목들입니다. 샘플 JSON에서 실제 키 이름을 확인하세요. |
| 시간이 9시간씩 밀려 보임 | e-Class가 타임존 없는 시각을 주고 브라우저 타임존이 한국이 아닌 경우입니다. 브라우저/OS 타임존을 확인하세요. |
